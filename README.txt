Handball Academy Manager — نسخة الويب (آيفون + كمبيوتر + أندرويد)
================================================================

نفس مشروع Firebase القديم (handball-academy-manager-fe8e4) ونفس البيانات.
مش محتاج Android Studio ولا Cloud Functions ولا خطة Blaze المدفوعة.

الملفات:
- index.html ........ التطبيق
- manifest.json + الأيقونات ... علشان يتسطب كتطبيق على الشاشة الرئيسية
- firestore.rules .... قواعد الحماية (هتنسخها في Firebase مرة واحدة)

خطوة 1 — قواعد الحماية (مرة واحدة، من الموبايل أو الكمبيوتر)
  Firebase Console ← المشروع ← Firestore Database ← تبويب Rules
  امسح الموجود، والصق محتوى firestore.rules كله، واضغط Publish.

خطوة 2 — تأكد إن الدخول بالبريد مفعّل
  Authentication ← Sign-in method ← Email/Password = Enabled

خطوة 3 — ارفع الملفات على النت (اختار طريقة)
  أ) Netlify Drop (الأسهل من الكمبيوتر): ادخل app.netlify.com/drop واسحب الفولدر كله.
  ب) GitHub Pages (ينفع من الموبايل): اعمل Repository عام، ارفع كل الملفات،
     وبعدين Settings ← Pages ← Branch: main ← Save.
  ج) Firebase Hosting لو عندك Firebase CLI على الكمبيوتر.
  ارفع كل الملفات مع بعض في نفس الفولدر.

خطوة 4 — أول دخول
  - لو عندك حساب مدير متعمل قبل كده: ادخل بيه عادي.
  - لو لسه: افتح الرابط واضغط "أول مرة؟ إنشاء حساب المدير".
    الزرار ده بيشتغل مرة واحدة بس، وبعدها بيختفي ومحدش يقدر يعمل مدير تاني.
  مهم: لو المدير متعمل قبل كده، افتح التطبيق وادخل بحسابه أول ما ترفعه، علشان التطبيق
  يسجّله كمدير أساسي ويقفل زرار "إنشاء حساب المدير".

التسطيب على الأجهزة:
  - آيفون: افتح الرابط من Safari ← زرار المشاركة ← "إضافة إلى الشاشة الرئيسية".
  - أندرويد: افتح الرابط من Chrome ← القائمة ⋮ ← "تثبيت التطبيق" أو "إضافة للشاشة الرئيسية".
  - الكمبيوتر: افتح الرابط من Chrome أو Edge ← أيقونة التثبيت في شريط العنوان (أو استخدمه من المتصفح عادي).

حسابات الكباتن:
  المدير ← الفرق ← "حسابات الكباتن": الاسم + البريد + كلمة مرور + الفريق.
  "إيقاف" بيمنع الكابتن من الدخول. البريد اللي اتوقف ماينفعش يتعمل بيه حساب جديد؛ استخدم بريد تاني.
  الكباتن اللي اتعملوا في النسخة القديمة شغالين عادي.

التحديث بعد كده: ارفع index.html الجديد مكان القديم، والكل يشوف التحديث على طول.
